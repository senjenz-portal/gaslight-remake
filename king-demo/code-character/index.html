The King, written in code

The same King as the mesh demo — but there is no model file here. Every part below (head, hair, greatcoat with its orange lining, waistcoat, boots) is authored as native Three.js geometry by the img2threejs character method: one reference image → measured proportions → sculpt spec → this factory. A real bone skeleton drives procedural walk and idle cycles in sim-time. The rigged GLB was used as a measurement target only — nothing from it is loaded on this page.
